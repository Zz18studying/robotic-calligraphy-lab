# 中期检查怎么准备

按下面顺序准备即可。项目的总目标来自原申报书与开题 PPT；本仓库的实际完成范围以[截至目前的研究报告](截至目前的研究报告.md)为准。

## 先看哪些文件

1. **先读本报告**：[截至目前的研究报告](截至目前的研究报告.md)。重点读第 1、3、4、5、6 节，能讲清“要解决什么、做了什么、如何评价、数字代表什么、还有什么没做”。
2. **再看入口说明**：[README](../README.md)。按命令跑一次单字演示，确认自己的电脑能复现。
3. **看 4 张图和 1 个动画**：`outputs/ppt_demo/永_standard/target.png`、`fixed.png`、`open_loop.png`、`closed_loop.png`、`comparison.png` 和 `writing.gif`。重点看轮廓匹配、漏写（蓝色）、越界（红色），不要只展示最终黑字。
4. **看真实输出数据**：`calibration.csv` 是 15 次虚拟试笔；`planned_actions.json` 是初始规划；`executed_actions.json` 包含反馈后实际执行的后续笔画；`metrics.json` 包含逐笔纠偏和整字指标。
5. **最后看代码**：按 `sim_data.py → sim_brush.py → sim_planner.py → sim_control.py → sim_cli.py` 读。`sim_suite.py` 负责批量对照，`geometry.py` 是几何工具。无需逐行背代码，能指出每个文件的输入和输出即可。

## 运行什么代码

在 `calligraphy_midterm` 文件夹打开 PowerShell，先安装依赖：

```powershell
python -m pip install -e .
```

若电脑上命令是 `py`，可把下方 `python` 换成 `py`。查看原始数据里的“永”字：

```powershell
python scripts/inspect_make_me_a_hanzi.py 永 --out outputs/ppt_demo/dataset
```

跑单字闭环演示：

```powershell
calligraphy-sim --char 永 --profile standard --size 256 --out outputs/ppt_demo
```

演示反馈更明显的扰动环境：

```powershell
calligraphy-sim --char 永 --profile offset --size 256 --out outputs/ppt_demo
```

复现报告中的 21 组和补充 15 组：

```powershell
calligraphy-sim-suite --size 192 --out outputs/closed_loop_sim
calligraphy-sim-suite --chars 中天春秋月 --size 192 --out outputs/heldout_sim
python -m unittest discover -s tests -v
```

批量命令只更新两份 `suite_metrics.csv` 和 `实验结果.md`，不会再产生几十个重复的图片文件。若命令行入口没有安装成功，可先执行 `$env:PYTHONPATH='src'`，再用 `python -m calligrapher.sim_cli ...` 或 `python -m calligrapher.sim_suite ...`。

## 必须理解的 8 件事

1. **笔顺从哪里来**：来自 Make Me a Hanzi 的有序笔画数据，不是当前程序通过大模型推算，也不是运行时联网搜索。
2. **中心线做什么**：给初始运动方向；目标轮廓的左右宽度与偏移决定轨迹修正和下压。中心线本身不足以描述毛笔的铺毫与侧锋。
3. **下压怎样得到**：15 次虚拟试笔测宽度，最小二乘拟合后反求目标宽度所需下压。它是归一化指令，不等于牛顿力。
4. **速度怎样得到**：按曲率与起收笔规则设置，相对速度也进入试笔拟合；目前没有真实速度演示数据，不能说它由大数据训练出来。
5. **“学习”指什么**：本阶段是回归拟合和系统辨识，属于机器学习的简单形式；没有深度学习模型训练，也不需要 GPU 服务器。
6. **闭环看什么**：只看写前和写后的累计纸面图像之差，估计新墨迹，修正**下一笔**。不读取仿真器隐藏偏差，也不是笔画进行中的实时反馈。
7. **loss 怎么算**：标定用宽度均方误差 `L_cal`；整字展示用 IoU 和 `L_ink=(漏写+2×越界)/目标面积`。越界权重是设计选择。
8. **结果能证明什么**：证明当前合成环境里闭环比对照好；不能证明真机可写、风格已学会、跨硬件泛化或达到申报书目标。
